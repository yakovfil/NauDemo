# Demo font

`Abel-Regular.ttf` is Abel from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/abel

Source download: https://raw.githubusercontent.com/google/fonts/main/ofl/abel/Abel-Regular.ttf

SHA-256: `8809dcad25318225052f88333e208c5aad4adcb7b2c934c135735ec19aa410b4`

Redistribution is covered by the accompanying `OFL-Abel.txt`.
Both demo targets and CPU text tests use these exact bytes.

The initial engine text capability accepts project-controlled TTF assets up to
16 MiB, single lines up to 4096 Unicode codepoints, sizes from greater than zero
through 512 logical pixels, and raster scales greater than zero through 8.
Coverage dimensions are limited to 4096 per axis and 16 MiB per bitmap.
It supports glyph advances and kerning; complex script shaping is not included.
